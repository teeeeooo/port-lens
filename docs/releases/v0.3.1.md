# Port Lens v0.3.1 Preview

Port Lens v0.3.1 is the post-PR #4 stability baseline for the current Windows preview.

## Highlights

- improved Windows listener refresh responsiveness and process observability
- managed App stdout/stderr capture, exit diagnostics, and safer command handling
- persistent registration of already-running external listeners as monitoring-only Apps
- verified managed-runtime reattach after Port Lens restart, including PID-generation, creation-time, command-line, and ancestry checks before lifecycle authority is restored
- compact positioning that can sit directly against the Windows work-area/taskbar boundary
- registered-App hover panel in compact mode using a dedicated `compact-hover` window
- stable expanded-window restore without cumulative size growth
- compact drag stabilization with polling suppression only during actual drag and unchanged-snapshot render deduplication
- preserved mixed-DPI/multi-monitor positioning, saved compact position, startup gating, tray lifecycle, and compact clipping

## Known preview limitation

On the tested Windows machine, compact drag initiation can still show a brief hitch/jump on roughly 3 of 10 drag starts when monitoring/render work overlaps gesture start. Persistent cursor offset and sustained catch-up jump are not expected once movement is underway. This residual is accepted for the v0.3.1 preview.

## Windows packages

The release publishes NSIS, MSI, and single-EXE Portable x64 packages plus `SHA256SUMS.txt`. Packages remain unsigned, so SmartScreen or managed-device security policy may warn or block execution.

## Scope after v0.3.1

UDP listener discovery and HTTP health checks remain deferred future work. Silent lifecycle adoption of arbitrary externally started processes is intentionally not planned; lifecycle authority is limited to Port Lens-started runtimes or runtimes that pass verified reattach checks.
