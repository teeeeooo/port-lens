# Port Lens v0.3.2 Preview

This patch release includes PR #5 and PR #6 and completes the currently requested project scope.

## Changes

- Improve compact drag session cleanup, cancellation, hover coordination and refresh recovery after gestures and Open.
- Bound pending drag movement requests and prevent stale responses from affecting a newer gesture.
- Move managed-runtime probes off the event thread and protect managed processes from unmanaged Kill through another listening port.
- Remove automatic registered-App stdout/stderr capture and App-specific Logs buttons. Each App owns its own logs.
- Retain Start/Stop/Restart requests/results and observed process lifecycle information in Port Lens diagnostics, with the existing 1 MiB rotation threshold and one previous file.
- No Port Lens log collectors remain after Quit; managed Apps continue independently.

## Upgrade notes

Stop test/managed Apps in the previous Port Lens version, quit it, then start them with this version to replace inherited old output handles. Existing historical log files are not deleted. App-owned log files and explicit shell redirection are unaffected. Port Lens diagnostics remain available under Settings → Diagnostics → Open logs.
